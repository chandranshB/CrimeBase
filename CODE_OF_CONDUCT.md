# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive; no harassment, discrimination, personal attacks or publishing others' private information. This matters doubly here: the data concerns real crime and real victims, so keep discussion factual and never post identifying details of victims or suspects in issues or pull requests.

Report violations privately via GitHub's "Report a vulnerability / contact" options on this repository or to the maintainer, [@chandranshB](https://github.com/chandranshB). Maintainers may remove content and block participants who breach these standards.
